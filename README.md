# Inkvault

A 3D shelf for your own comic files (CBR, CBZ, PDF, EPUB). Spines stand side by side on a glass shelf; the active issue turns out to show its cover, opens into a detail page, and reads in a full-screen reader.

- Everything stays on your device. Only covers and titles are saved in the browser; comic files are never uploaded or copied.
- Add a whole folder (desktop Chrome/Edge remember it), or select files on mobile.
- Installable web app with offline support.

Static site: no build step. Deploys as-is on Vercel.
